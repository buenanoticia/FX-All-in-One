# FX All-in-One Pro — 総合案内

更新日：2026年10月27日  
対象：TradingView / Pine Script v6

ダウ理論、エリオット波動候補、グランビル候補、サポート・レジスタンス、移動平均線、ATR・固定幅による距離目安をまとめた、チャート分析補助用インジケーターです。

**USDJPY専用版、クロス円汎用版、NOKSEK専用版、AUDNZD専用版を、別ファイル・別バージョンとして管理します。** 各追加版は既存版を置き換える上位互換版ではありません。このREADMEは総合案内です。詳しい仕様・設定・制約は各版のREADMEを参照してください。

**自動売買システムではありません。** 実口座への発注、注文変更、建玉管理、実際のトレーリングストップ管理は行いません。

**USDJPYにはUSDJPY専用版を使用してください。** クロス円版の「汎用」は、上記6ペアに対応する意味です。すべての円通貨ペアへの対応、複数ペアの同時監視、ペアごとの自動最適化という意味ではありません。いずれの版も、表示中のチャート1銘柄を分析します。

対象外の銘柄では誤使用を防ぐため停止します。NOKSEKとAUDNZDには新しい各専用版を使用します。今回追加した2版は実機未確認の初回配布です。

## 共通する6つの機能

| 機能 | 内容 |
|---|---|
| 移動平均線 | 初期値EMA20・75・200。種類・期間を設定可能 |
| サポート・レジスタンス | 確定ピボットを集約した水平線。探索期間の初期値は300本 |
| ダウ理論 | 高値・安値の構造、トレンド状態、防衛ラインを表示 |
| エリオット波動候補 | 確定ピボットに基づく簡易候補。理論の完全実装ではない |
| グランビル候補 | 本スクリプトの条件による①〜④のサインとアラート |
| ATR・固定幅の距離目安 | ATR×倍率、固定pips、ATR×倍率＋下限の3方式と参考金額 |

売買サインは表示チャート足の確定時に判定します。ただし、移動平均線や現在値を使った距離目安などは、形成中の足でも動きます。ピボットの判定には右側の足の確定待ちがあり、「遅延なし」「完全非リペイント」を保証するものではありません。

詳細は [USDJPY版](usdjpy/README.md)、[クロス円版](jpy-cross/README.md)、[NOKSEK版](noksek/README.md)、[AUDNZD版](audnzd/README.md)を参照してください。

## 導入方法

対象に合う版の `.pine` ファイルを開き、TradingViewのPineエディタで新しいインジケーターに全文を貼り付けて保存し、対象チャートへ追加します。同じフォルダーの `.txt` も同内容です。既存スクリプトの末尾へ追記する方法ではありません。

まず通常の5分足で、銘柄、配信元、設定、パネルの数値を確認してください。各版を別名で保存し、対象に合わない版はそのチャートから外します。通常の時間足チャートを対象とし、平均足・Renko・レンジ等の非標準チャートやティック足は対象外です。

追加直後だけでなく、次の足へ切り替わった後もエラーなく表示が続くことを確認してください。アラートは使用する版・銘柄・時間足・設定に合わせて作成します。コードや設定を更新した場合の扱いも含め、各版READMEのアラート設定を確認してください。

## 設定で混同しやすい点

| 項目 | 注意 |
|---|---|
| 初期の幅計算 | 全版とも5分足ATR(14)×2.5。20pips固定ではない |
| 固定幅・下限幅 | 初期値は各20.0pips。該当方式を選択した場合だけ使用する |
| 設定値の位置付け | 比較用の初期値。各ペアに最適化した推奨値ではない |
| USDJPY版の参考スプレッド | 初期値2.6pipsの手入力値。ライブ取得ではない |
| クロス円版の参考スプレッド | 6ペアそれぞれに入力欄と「設定済み」チェック。初期状態は未設定 |
| クロス円版の幅・数量・ATR設定 | 共通入力。ペア変更時の自動調整なし |
| 参考数量 | 基軸通貨数。EURJPYの3,000は3,000 EUR。実注文の数量は変更しない |
| 値幅の円換算 | 円ペアは数量×価格差で円。非円ペアは決済通貨金額を別途換算。必要証拠金・維持率・損失上限ではない |
| NOKSEK/AUDNZDのpip | 初期値0.0001。注文画面と照合。手動指定は仕様確認時のみ |
| NOKSEK/AUDNZDの参考SP | 各専用版で手入力。初期未設定 |
| NOKSEK/AUDNZDの円換算 | TradingView日次参考レート／手入力／OFF。実口座の換算値ではなく、取得不可を0円にしない |

**チャートのドット線は「現在値からの距離目安」です。** 一度有利に動いた逆指値を固定する本物のトレーリングストップではなく、注文も出していません。防衛ラインや「目安④」も、証券会社に受け付けられた決済注文ではありません。
