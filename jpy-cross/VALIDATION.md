## TradingViewで確認する操作

| 操作 | 期待される結果 |
|---|---|
| 新しいスクリプトに全文貼付・保存 | コンパイルの結果を確認する。既存USDJPYコードには追記しない |
| 対象クロス円の通常5分足に追加 | 短縮名 `JC 1.0.0`、現在のペア・配信元・MA・パネルを確認 |
| 次の5分足まで観察 | 履歴バッファエラーなく更新が継続するかを確認 |
| 6ペアを順番に切替 | 銘柄・基軸単位・該当SP行が切り替わる。全ペア同時表示ではない |
| EURJPYだけSP設定済みにする | EURJPYで参考値表示。GBPJPY等はそのペアも設定するまで未設定 |
| SP値を入れ、設定済みをOFFに戻す | 金額0円とせず未設定に戻る |
| SP注意境界0、次に正の値 | 0なら境界チェックOFF、正値なら手入力SPとの大小だけで注意 |
| 固定20/25・3,000基軸通貨 | 600/750円。1pip換算30円、単位EUR/GBP等が正しい |
| 固定幅だけ変え、ATR方式を選ぶ | 固定幅の入力は使われずATR由来の候補になる |
| 1分・5分・15分・1時間へ切替 | 上位/同一/下位ATR取得を確認。履歴不足や下位足未終了なら取得不可 |
| S/R探索50・300・4900 | バッファ不足なく描画するか、負荷も含めて確認 |
| パネルOFF/ON | 全16行が消去・再表示される |
| 通常足から非標準足へ切替 | 対象外という説明で停止する |
| USDJPY、EURUSD、NOKSEKへ切替 | 対象6ペアではない旨で停止する（想定どおりのガード） |
| 対象ペアへ戻す | 銘柄切替で再計算し、通常表示するか確認 |
| 別配信元の対象クロス円 | パネルに当該FOREXCOM銘柄との照合注意が出る |
| ペア・時間足ごとにアラート作成 | バー終値ごとに1回。配信を別途確認。チャート切替で既存アラートは切り替わらない |

コンパイルエラーと、意図的な対象外ガードと、予期しない実行時エラーを区別してください。予期しないエラーで止まった表示を最新の分析結果として使わないでください。実際の注文や逆指値はこのインジケーターと独立しています。
