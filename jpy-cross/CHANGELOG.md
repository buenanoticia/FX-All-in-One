# CHANGELOG — JPY Cross

## v1.0.0 — 2026年10月26日

USDJPY v1.1.1から分岐した、独立したクロス円版の初版です。USDJPY版のバージョン番号を進めたものではなく、既存ファイルも上書きしていません。スクリプト名は `FX_AllInOne_JPY_Cross.pine`、表示短縮名は `JC 1.0.0` です。

### 変更・追加

| 項目 | クロス円版の仕様 |
|---|---|
| 対象銘柄 | EURJPY / GBPJPY / AUDJPY / NZDJPY / CADJPY / CHFJPY |
| 銘柄チェック | FX種別・基軸通貨・決済通貨の組み合わせで判定 |
| 対象外 | USDJPYは既存専用版。NOKSEKや未定義の円ペア等は停止 |
| 参考SP | 6ペア別の手入力と設定済みチェック。初期値は未設定 |
| 未設定表示 | 0コストとして表示せず「未設定」とする |
| SP注意境界 | 共通入力、初期値0でOFF。旧版3.0pipsは流用しない |
| 数量 | 基軸通貨数として解釈。EUR/GBP等の単位をパネル表示 |
| 金額表示 | 円での1pip換算と採用幅換算を表示 |
| 配信元 | 現在のペアと配信元を表示。他社フィードには当該FOREXCOM銘柄との照合を促す |
| パネル | 14行から16行へ。追加行に合わせツールチップとクリア範囲を調整 |
| 固定幅等の説明 | 共通入力、ペア切替による自動調整なし、未最適化であることを明記 |

### 継承・変更しない部分

MA、S/Rクラスタリング、ダウ、エリオット候補、グランビル候補の計算・状態遷移・サイン、ATRの時間足取得と幅計算、8種類のアラート条件はUSDJPY v1.1.1と同一です。これらの共通ブロックはソースのハッシュ比較でも確認しています。

履歴バッファ対策 `max_bars_back(time, 5000)`、S/R探索期間の初期値300・上限4900、ピボットの確定待ち、確定足だけのサインとアラート、上位/同一/下位足ATRの分岐、欠損時の別時間足への代用禁止、数値書式修正を引き継ぎます。

`indicator()` のままであり、strategy化、発注、建玉同期、本物のトレーリングストップ管理、リアルタイムSP取得は追加していません。複数銘柄のスキャナーも追加していません。

### 互換性

旧USDJPY版とは対象銘柄が異なります。旧版のコードに追記せず、別のPineスクリプトとして保存してください。アラートはクロス円の対象ペア・時間足ごとに新しく作成します。

固定幅20pips、下限20pips、ATR倍率2.5、低高ボラ境界3/8、数量3,000は共通の比較用初期値です。同じパラメーターで全6ペアの成績が検証済みという意味ではありません。SP以外はペア別プリセットにはしません。

### 検証状況

静的・Python参照テスト96件通過。TradingViewでのコンパイル・6ペアのライブ実行・アラート実配信・バックテストは未実施です。詳細は `VALIDATION.md`、ソース差分は `changes_from_USDJPY_v1_1_1.patch` に記録しています。
