## 重要：円ペアの計算をそのまま使わない

非円FXで一般的なpip単位0.0001を初期設定としています。[FX2] `syminfo.mintick` は配信価格の最小刻みであり、1pipと同一とは限りません。パネルには「1pipの価格差」と「最小刻み」を両方表示します。

初期設定で20pipsの価格差は **0.0020 NZD** です。0.20円でも20銭でもありません。

```text
1pip金額（NZD） = 数量（AUD） × pip単位
幅の金額（NZD） = 数量（AUD） × 幅候補pips × pip単位
SPの金額（NZD） = 数量（AUD） × 手入力SPpips × pip単位
参考円換算          = NZDの金額 ×（1 NZD当たりの円）
```

| 数量 | 値幅 | 決済通貨建ての値幅換算 |
|---:|---:|---:|
| 3,000 AUD | 1pip | 0.30 NZD |
| 3,000 AUD | 20pips | 6.00 NZD |
| 3,000 AUD | 25pips | 7.50 NZD |
| 3,000 AUD | 50pips | 15.00 NZD |

**金額は必要証拠金、維持率、実効レバレッジ、実際の含み損益、損失上限ではありません。** スプレッド、スワップ、手数料、約定のずれを自動で合算せず、実口座とは連動しません。小さな円換算額だけを理由に数量を増やすための計算機ではありません。

設定「0」の手動pip指定は初期値OFFです。ブローカーの単位が異なると仕様確認できた場合に限り、手動指定をONにし、1pipの価格差を入力します。変更はATRのpips換算、固定幅、手入力SP、金額換算すべてに影響します。注文画面の「pips」「points」「価格」の違いを先に確認してください。

## 日本円の参考換算

設定「6B」で換算方法を選択します。

| 方法 | 動作 |
|---|---|
| 自動（日次参考） | `request.currency_rate("NZD", "JPY", ignore_invalid_currency=true)` に相当する日次レートを使う。初期選択 |
| 手入力 | 「1 NZDは何円か」を入力。正の値だけ使用 |
| 表示しない | 円換算をOFFにし、NZD金額だけを使う |

TradingViewの `request.currency_rate()` は日次換算レートを返します。[TV1] **FOREX.comのリアルタイムレートや決済時換算ではなく、ブローカー損益との一致は保証されません。** 当該関数から元データの時刻は取得していないため、パネルには日次参考と表示し、最新の為替取引時刻を装って表示しません。ATR行の時刻はATR元バーの終了時刻であり、円換算時刻ではありません。

レートが取れない、または正の値でない場合は **「円換算不可（0円ではない）」** と表示します。0円や1倍の換算で穴埋めせず、自動取得に失敗しても手入力値へ黙って切り替えません。その場合もNZD金額と分析表示は継続します。

手入力モードの0は未設定です。例えば説明用に **1 NZD＝90円** と仮定するなら、入力は `90` です。逆数ではありません。3,000 AUD・20pipsの6 NZDは、参考換算 **540円** になります。これは計算確認用の架空レートで、現在の相場を示していません。

手入力レートは全バー共通の入力です。過去時点の換算レートを再現する機能ではなく、過去損益の厳密検証にも使いません。

## 参考スプレッド

設定「6A」でAUDNZDの値をpipsで入力し、「AUDNZD SP設定済み」をONにします。初期状態はOFFで、「未設定（0コストではない）」と表示します。値だけ入力してもチェックOFFの間は使いません。

初期pip単位なら、買値と売値の価格差が0.00030 NZDの場合は3.0pipsです。実際の表示スプレッドや入力単位と照合してください。FOREX.comは変動スプレッドなので、過去に入れた値が現在も有効か確認が必要です。[FX1]

注意境界の初期値0は境界チェックOFFです。正の境界を設定し手入力SPがそれを超えると注意表示します。幅候補が手入力SP以下の注意は、境界チェックとは別に出します。

**これらは表示上の注意だけです。** サイン・アラート・注文を停止しません。手入力の鮮度も判定しません。pip単位を手動変更した場合はSP入力も再確認してください。

## 引き継ぐ6機能と制約

| 機能 | 内容・制約 |
|---|---|
| MA | EMA20・75・200が初期値。SMA切替可能。表示足の価格で計算 |
| S/R | 確定ピボットを50期間ATR×0.5で集約。初期探索300本・最大6線。回数表示はピボット候補数 |
| ダウ理論 | HH/HL/LH/LL/EH/EL、高安構造・終値ブレイク、防衛ライン。初期左右5本の確定待ちあり |
| エリオット候補 | 第1〜第5波終点の簡易候補。複雑な修正波を含む理論の完全実装ではない |
| グランビル候補 | ①価格とMA交差、②MAをまたいだ復帰、③MAを割らない接近反発、④乖離と逆向き形状 |
| 距離目安 | ATR×倍率／固定pips／ATR×倍率＋下限。実注文・最高値最安値追随はしない |

サイン・トレンド状態・波動候補の更新は表示足の確定時のみです。MAや現在値からのドットは未確定足でも動きます。確定ピボットは右側の足が必要です。ラベルの初期位置は「判明した足」であり、過去位置表示を選ぶときも、その過去時点で知っていた情報とは扱いません。

エリオット内部状態1は第2波調整候補、2は第3波推進候補、3は第4波調整候補、4は第5波推進候補、5は第5波終点候補です。第3波候補一致アラートは状態2に限定し、状態3を含めません。波動候補とダウ方向が食い違う場合もあります。第3波・星印は高勝率を実証した印ではありません。

④は建玉・約定価格・損益を参照しません。未保有や含み損でも表示され、利益確定を保証しません。200MAフィルターは初期値OFFで、線が見えることとフィルター有効は別です。

## ATRと幅の設定

| 項目 | 初期値 |
|---|---|
| ATR時間足・期間・倍率 | 5分・14・2.5 |
| 幅候補方式 | ATR×倍率 |
| 固定幅・下限幅 | 20.0pips・20.0pips。対応方式を選んだときだけ使用 |
| 幅の切り上げ単位 | 0.1pip |
| 低ボラ／高ボラ境界 | 3.0／8.0pips |
| 参考数量 | 3,000 AUD |
| 参考スプレッド | 未設定 |
| 円換算 | 自動（日次参考）。手入力値は0＝未設定 |
| パネル | 右下・小。全19行 |

**これらは引き継いだ比較用の初期値で、AUDNZDに最適化した推奨値ではありません。** 5分ATR×2.5をFOREX.comの推奨方式とする根拠もありません。固定20pipsを確認するときは、数値欄だけでなく計算方法を「固定pips」に変更します。

「ATR×倍率＋下限」は上限ではありません。ATR増大時は下限より広い幅になります。低ボラ・中間・高ボラ色は設定境界との大小を表し、取引の安全性やスプレッドの適切さを判定しません。

表示足よりATR足が長ければ前の確定上位足を使用し、同じなら直近確定値、短ければ終了済み下位足データを使用します。取得不可のときは別時間足のATRで代用しません。下位足未終了などで欠損する場合もあります。固定幅だけはATR欠損でも表示できます。[TV1]

幅候補を指定pips単位へ切り上げてから金額を計算します。例えば価格ATR0.00043、pip単位0.0001なら4.3pips、倍率2.5で10.75pips、採用幅10.8pips、3,000 AUDでは3.24 NZDです。これは計算例です。

ドットは `close ± 幅候補` を価格最小刻みに丸めた目安です。価格やATRが変われば不利方向にも戻ります。実トレーリングストップは、別途ブローカーで発注し、受付・対象数量・初期逆指値価格を確認してください。インジケーターの設定変更は既存注文を変更しません。

`max_bars_back(time, 5000)` を引き継ぎ、探索上限4900本の描画用履歴を事前確保しています。探索期間を5000本にする設定ではありません。旧版での修正報告は本版の実機確認の代わりにはしません。
