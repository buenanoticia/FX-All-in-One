# CHANGELOG — NOKSEK

## v1.0.0 — 2026-10-27

JPY Cross v1.0.0から独立したNOKSEK専用版を作成しました。既存USDJPY・JPY Cross版は変更していません。

| 変更点 | 内容 |
|---|---|
| 銘柄ガード | FX種別・NOK基軸・SEK決済に限定 |
| pip単位 | 初期値0.0001。仕様照合時の手動指定を追加 |
| 数量 | 基軸通貨NOKで明示 |
| 金額 | まずSEKで計算。円と誤表示しない |
| 円換算 | 日次参考／手入力／OFF。欠損は0円にせず取得不可 |
| SP | NOKSEK専用入力。未設定チェック・注意表示 |
| パネル | 19行。元通貨額・円換算額・レート・pipと最小刻みを区別 |

MA/SR/Dow/Elliott/Granville、ATR取得・幅計算、8アラートのコードブロックは派生元と同一です。ATR関連入力のラベル・説明文だけを専用版へ合わせています。`max_bars_back(time, 5000)` を維持しています。

pip単位・対象データが異なるため、JPY Crossでのサインや金額をそのまま再現する趣旨ではありません。数量や幅は未最適化です。Pineのコンパイル、ライブ動作、実際の円換算取得、バックテストは未実施です。
