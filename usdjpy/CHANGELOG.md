# CHANGELOG — USDJPY v1.1.1

更新日：2026年10月26日

## v1.1.1 — S/R描画の履歴バッファ修正

対象の報告：v1.1.0、5分足、`Error on bar 5784`、過去参照300本に対して履歴上限299本、`#main():131`。

原因箇所はS/R水平線を生成する `line.new()` です。バー番号を使う過去座標の描画が内部で `time` の履歴を参照するため、ライブ更新時に自動確保済みの範囲を超える場合がありました。TradingViewの公式仕様と、利用者のエラー画像・該当コードを照合しました。仕様出典はREADMEの[TV8]〜[TV10]です。

### コード変更

`indicator(...)` の後に `max_bars_back(time, 5000)` をグローバルで追加しました。S/R探索期間の上限4900本と、過去位置ラベルの最大100本をカバーします。全系列のバッファを拡大する指定は追加していません。

版表示を `v1.1.1`、短縮名を `UJ 1.1.1` に変更し、追加箇所にコメントを記載しました。実コードの差分は `changes.patch` に収録しています。

### 変更していないもの

S/Rの探索期間・クラスタリング・最大表示本数、MA、ダウ、波動候補、グランビル、サイン確定条件、ATR取得・倍率・丸め、固定幅と下限幅、数量と参考スプレッド、アラート条件、USDJPY制限はv1.1.0から変えていません。設定の追加・削除もありません。

今回の変更は売買ロジックの変更ではありません。市場データの更新・後日のデータ訂正や入力値の違いによる表示差まで否定するものではありません。探索期間を299本に縮める、300本前の候補を捨てる、S/Rを非表示にするという回避策にはしていません。

### 文書と検証

READMEに原因・手修正・全文差し替え・ライブ更新確認手順を追加しました。VALIDATIONは今回の確認範囲に更新しました。引き継いだ58件のテストと、新たな履歴範囲・差分確認10件を実行し、68件が通過しました。全て静的検査またはPython参照モデルであり、Pineコンパイル・ライブ実行・売買バックテストではありません。

旧版のアラートは新版で作り直してください。チャート上のコード変更は、作成済みアラートへ自動反映されません。ブローカーの注文を変更する機能は追加していません。

## v1.1.0 — 初期修正版の変更履歴

更新日：2026年10月26日

## 変更の要約

元のMA、S/R、ダウ、波動候補、グランビル候補、ATR距離という構成を維持し、レビューで見つかった表示・時間足・確定条件・説明上の問題を修正しました。実注文を送信する機能や本物のトレーリングストップは追加していません。

| 対象 | 旧版 | v1.1.0 |

| 小数の文字列書式 | `"#.1"` を使用 | 1桁表示に `"0.0"` を使用 |
| 計算値と表示値 | 幅の表示を注文へ転記すると内部値と区別しにくい | ATR倍率の丸め前値と、指定単位へ切り上げた幅候補を分離 |
| ATRの下位足取得 | 無条件に下位足関数を呼ぶ | 要求時間足が表示足より短い場合だけ呼ぶ |
| ATRの上位足取得 | 未確定の上位足を含み得る | ATRと終了時刻の `[1]` を `lookahead_on` と組み合わせる |
| ATRの同一時間足 | 未確定値を含み得る | 表示足の直近確定値を使用 |
| ATR欠損時 | 表示時間足のATRへ暗黙に置き換える | 欠損を保持。「取得不可/待ち」、別時間足への代用なし |

| ドット線 | 「トレール目安」 | 「距離目安（注文・追随なし）」と明記。close±距離という基本計算は維持 |

| 売買サイン | 未確定足で出現・消失し得る | 全売買候補を `barstate.isconfirmed` でゲート |
| トレンド・波動状態 | 未確定足でも更新 | 確定足で更新 |
| グランビル前足比較 | 前足終値を現在のMAと比較 | 前足終値を前足MAと比較 |
| グランビル② | 波動候補なら浅い接近でも②になり得る | MAをまたいだ復帰を必要条件にする |

| 波動無効化 | 終値だけの一部検査、再定義、残存価格あり | 確定足の高安も使用。無効化で方向・終点価格を一括消去 |

## 互換性と注意

サインの確定条件、②③の分類、波動の無効化と時間順序、ラベルの表示位置が変わっています。旧版の過去サインと一致しないことは、単なる見た目の問題ではなく仕様変更です。旧版の優位性が新版へ引き継がれたとは判断できません。

ATRの初期時間足5分・期間14・倍率2.5、MA20/75/200、長期MAフィルターOFFは維持しています。幅モードの初期値もATR×倍率であり、固定20pipsや下限20pipsが自動で有効になるわけではありません。

アラート名も変更しています。旧版で作ったアラートは削除し、新版で作り直してください。実口座の注文・建玉には、この更新は何も変更を加えません。

## 追加していない機能

実約定の同期、実ストップの片方向追随、Webhook自動売買、バックテスト用の `strategy()`、口座残高・証拠金管理、ライブスプレッド取得、経済指標カレンダー連携、最適幅の自動選定は追加していません。
