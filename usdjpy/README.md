## v1.1.1：ライブ更新時の履歴バッファ不足を修正

2026年10月26日、利用者提供の画像で、v1.1.0の131行目のS/R水平線描画において次の実行時エラーを確認しました。

```text
Error on bar 5784: The requested historical offset (300)
is beyond the historical buffer's limit (299).
at #main():131
```

v1.1.0では `barstate.islast` のブロック内で、保持している過去ピボットのバー番号を起点に `line.new()` を実行しています。バー番号による描画は内部で `time` 系列の履歴を参照します。必要な参照幅を自動推定だけに任せていたため、ライブ更新で過去参照が増えた時に不足する構造でした。[TV8][TV9]

v1.1.1では、`indicator(...)` の後、グローバルスコープに次の1行を追加しました。

```pine
max_bars_back(time, 5000)
```

S/Rの探索期間の設定上限は4900本です。範囲外ピボットは描画前に削除され、4900本前の境界は保持するため、その範囲をカバーする5000本分の時刻履歴を事前確保します。ダウの過去位置ラベルの最大100本もこの範囲内です。`indicator(..., max_bars_back=5000)` による全系列の一括拡張ではなく、問題となる `time` だけを指定しています。[TV8][TV10]

**5000は履歴バッファの確保量であり、S/Rの探索期間を5000本に変更した意味ではありません。探索期間の初期値300本、MA、ダウ、波動候補、グランビル、ATR、幅モード、数量、参考スプレッド、アラート条件はv1.1.0のままです。** 表示の短縮名は `UJ 1.1.1` になりました。

## 主な機能：元の6機能と修正後の仕様

### 1. エリオット波動：確定ピボットによる簡易候補

ダウ用の確定ピボットを使い、上昇・下降それぞれの第1〜第5波の終点候補を管理します。パネルの内部状態は次の意味です。

| `waveCount` | 内部で得られている候補 | パネルの表示 |
|---:|---|---|
| 0 | 有効な候補がない | カウント待機 |
| 1 | 第1波の終点候補 | 第2波調整候補 |
| 2 | 第2波の終点候補 | 第3波推進候補 |
| 3 | 第3波の終点候補 | 第4波調整候補 |
| 4 | 第4波の終点候補 | 第5波推進候補 |
| 5 | 第5波の終点候補 | 第5波終点候補・警戒 |

候補はピボットの時間順序を確認して更新します。同じバーで高値・安値の両方がピボットとして確定した場合、そのバー内の順序を仮定して波動を進めません。調整の終点をまだ認識していない間に同方向の推進端が更新された場合は、第1波または第3波の延長候補として扱います。

第1波起点への到達・突破、第4波候補による第1波領域への重なり、確定済み第2波・第4波の調整端を更新する値動きを、確定足の高値・安値も用いて無効化条件にしています。第5波終点候補が得られた時点で、第3波の長さが第1波と第5波の両方より短ければ候補を棄却します。

無効化すると、波動方向と各終点価格をまとめて消去します。旧版のように、破綻した候補を自動的に別の第2波や第3波へ再定義して継続する動作はやめました。第5波終点候補の確定後は、ここで述べた進行中のヒゲ検査の対象外です。

**これはエリオット波動理論の完全実装ではありません。** 複雑な修正波、ダイアゴナル、延長・失敗波のすべて、全履歴区間を遡る厳密な整合性検証には対応しません。第3波最短の条件も、第5波終点候補が判明する前には完全には検証できません。

波動ラベルは、その時点で成立した候補の記録です。後に候補が無効化されても、過去の候補ラベルをすべて消して書き換える仕組みではありません。星印や第3波候補という名称は、高勝率・高期待値を実証した印ではありません。

### 2. グランビル：①〜④を使った独自条件

MAの向き、価格との位置関係、簡易ローソク足条件、ダウまたは波動候補を組み合わせます。伝統的な法則の全条件を厳密に再現したものではなく、本スクリプトの独自条件です。全サインは**表示しているチャート足が確定した時だけ**表示し、同じフラグをアラートに使います。

| サイン | 修正後の主な条件 |
|---|---|
| `★買②` / `★売②` | トレンドまたは初期波動候補、MAの向き、MAを一時的にまたいだ後の復帰、反発形状など |
| `買③` / `売③` | トレンド継続中、MAの向き、MAを割らない範囲での接近・反発、直前終値も同方向側など |
| `買①` / `売①` | 価格と基準MAの交差、MAの向き、ローソク足の方向など。初期値OFF |
| `目安④` | 表示足ATRによるMAからの大きな乖離と逆向き形状など。決済を検討するための参考表示 |

②では、前の足の終値を「前の足のMA」と比較するよう修正しました。波動候補に該当するという理由だけで、MAをまたいでいない浅いタッチを②に分類する条件は削除しました。③には、買いなら安値がMA以上、売りなら高値がMA以下である条件を加えています。このため、旧版と②・③の出る位置・回数が変わります。

①は**価格とMAの交差**であり、短期MAと長期MAのゴールデンクロス・デッドクロスではありません。①の有効・無効は②③のスイッチから独立しました。②③をOFFにしても、①だけをONにできます。

④は保有ポジション、約定価格、含み損益を見ません。旧表示「利確④」は利益確定を保証するように見えるため、「目安④」に変更しました。未保有時や含み損でも表示されます。売買候補と④が同じ足に出る可能性もあり、その場合はパネルに「④併発・要確認」と表示します。

長期MAフィルターの初期値は引き続きOFFです。MAを描画しているだけではフィルターは有効になりません。ONにすると、買い候補は長期MAより上、売り候補は下に限定します。パネルにON/OFFを表示します。

ローソク足条件のON/OFFは、足の確定待ちのON/OFFではありません。OFFでもサインは確定足のみです。クールダウン3本では、サインが出た足の後の3本を空け、最短で4本後から同方向の次の候補を許可します。

### 3. ダウ理論：スイング構造、防衛ライン、確定遅延

確定ピボットの高値・安値を比較して、HH、HL、LH、LLを表示します。高値同値・安値同値は、LHやLLと誤分類せず、EH・ELと表示します。

既知の高値・安値を使った終値ブレイクと、ピボット更新による高安の切り上げ・切り下げから、上昇・下降・レンジを判定します。終了条件は、元の「切り上げ・切り下げ重視」と「押し安値・戻り高値重視」を維持しています。防衛ラインの突破は終値で判定します。波動候補のヒゲによる無効化とは基準が違います。

**初期値の左右5本では、ピボットの右側5本が確定するまで判定できません。** 1時間足なら右側5本分の待ち時間があります。N波動の終値ブレイクを併用しても、参照するピボットの確定遅延が消えるわけではありません。

ラベルの初期位置を「そのピボットが判明した足」に変更しました。設定「ラベルを過去のピボット位置へ戻して表示」をONにすると旧版と同じ過去位置にも表示できますが、その過去時点で既に知っていたサインとして扱ってはいけません。ラベルのツールチップにピボット位置と判明位置を記載します。

防衛ラインは分析上の価格です。スプレッドやブローカーの注文仕様を考慮して発注されたストップ価格ではありません。

### 4. ATR・固定幅：トレール注文に転記する前の距離候補

初期値は、元の設定を引き継いだ**5分足ATR(14)×2.5**です。これは独自の比較検証用設定です。FOREX.comがこの組み合わせを推奨したという表現は削除しました。

#### 時間足の取得方法

| 表示チャート | ATR設定の例 | 使用する処理と値 |
|---|---|---|
| 1分足 | 5分 | 上位足として `request.security()` を使う。ATRと終了時刻の両方を1本前にずらし、`lookahead_on` と組み合わせる |
| 5分足 | 5分 | 表示足の直近確定ATR。足が形成中なら1本前の値 |
| 15分足・1時間足 | 5分 | `request.security_lower_tf()` で下位足配列を取得し、利用可能で終了時刻を過ぎた最新データを選ぶ |

上位足では、新しい上位足期間に入ってから、その1本前の確定値を使用します。未確定ATRを先取りする実装ではありません。下位足関数は、本当に選択時間足が表示足より短い場合だけ呼びます。

**データがないときに表示時間足のATRへ置き換えるフォールバックはありません。** 下位足の配列が空、計算に必要な履歴が不足、または有効な正のATRが得られない場合は「取得不可/待ち」と表示します。下位足の値を使う場合、新しい表示足の最初の5分など、終了済みの対象バーがまだ配列にない間も欠損表示になります。直前の表示足からの値の持ち越しはしていません。

パネルには選択ATRの時間足と、取得元バーの終了時刻を日本時間で表示します。時刻はデータの古さを確認するための情報であり、市場が営業中か、発注可能かを自動判定した表示ではありません。

下位足データには利用可能な履歴範囲の制約があり、提供元の後日のデータ訂正もあり得ます。全表示が絶対に変化しない、または「完全非リペイント」とは表現しません。

#### 幅候補の3方式

| 計算方法 | 計算 | 初期設定との関係 |
|---|---|---|
| `ATR×倍率` | 選択ATRをpips換算して倍率を掛ける | 初期選択。20pipsの下限は自動では付かない |
| `固定pips` | 入力した固定幅を使用 | 固定幅欄の初期値20.0pips。25.0等へ変更可能 |
| `ATR×倍率＋下限` | ATR由来の幅と下限幅の大きい方 | 下限欄の初期値20.0pips。上限幅は設けていない |

ATRが取得できない場合、ATRを使う2方式では幅候補も算出しません。固定pips方式だけはATRなしでも固定値を表示しますが、ATR未取得の注意を残します。

幅候補は、指定した切り上げ単位に合わせて上へ丸めます。初期単位は0.1pipです。**実際に注文画面へ入力できる単位や、許される最小ストップ距離を保証するものではありません。** ブローカー側の仕様を確認してください。

例えば、ATRが0.03084円なら3.084pipsです。倍率2.5では丸め前が7.710pips、0.1pip単位で切り上げた採用候補は7.8pipsです。パネルではATR×倍率の丸め前の値と、採用候補を別々に表示します。表示だけを1桁に丸めて、内部の幅と食い違わせる作りにはしていません。

旧版の数値書式 `"#.1"` は廃止しました。小数点以下1桁の表示には `"0.0"` を使います。ATRなどの表示は読みやすく丸めていますが、掛け算は表示丸め前の内部値で行います。

#### 色分けの意味

| 選択時間足のATR | 初期色 | 表示 |
|---|---|---|
| 3.0pips未満 | 水色 | 低ボラ |
| 3.0pips以上、8.0pips未満 | ライム | 中間 |
| 8.0pips以上 | オレンジ | 高ボラ |
| 取得不可 | 灰色 | 取得不可/待ち |

境界は独自の分類値です。「中間だから売買に適している」「高ボラなら必ず指標発表中」という意味ではありません。ATRを5分以外に変えても、この数値境界は自動補正されないため、比較基準を別途検討してください。低ボラ境界が高ボラ境界以上なら、設定エラーとして停止します。

#### ドット線は実際のトレーリングストップではない

買い側の線は `現在値 − 幅候補`、売り側は `現在値 ＋ 幅候補` です。方向が判定されている場合だけ対応する側を描きます。

買いの線でも価格が下がれば下へ戻り、ATR幅の変化でも位置が変わります。建玉開始後の最高値・最安値を保存せず、一度改善したストップを固定する処理もありません。表示名を「距離目安（注文・追随なし）」に変更しました。

本物のトレーリングストップを設定するには、別途ブローカーの注文画面で操作し、注文受付と実際の逆指値価格を確認する必要があります。Pine側の設定を変更しても、既存の実注文は変更されません。

### 5. サポート・レジスタンス：ピボットのクラスタリング

初期値で過去300本の確定ピボットを集め、50期間ATR×0.5の範囲で近接する価格をまとめます。条件を満たすグループを、含まれるピボット数の多い順に最大6本表示します。

v1.1.1では、この描画で使用する時刻履歴のバッファを明示的に確保しました。探索期間の判定、価格の集約方法、表示本数の条件はv1.1.0から変更していません。

ラベルの「回」はグループに含まれるピボット候補の数です。独立した売買機会の数、統計的に検証済みの反発回数を保証するものではありません。線の色やグループ化の結果は、現在値、ATR、探索範囲の更新で変化します。

### 6. MAと14行の状況パネル

MAの初期値はEMA20・75・200を維持しました。SMAへ変更できます。

| 行 | 内容 |
|---:|---|
| 1 | サインの判定時間足と、終値確定のみという条件 |
| 2 | ダウ理論の方向 |
| 3 | エリオット波動の簡易候補 |
| 4 | MAの並び |
| 5 | 基準MAの傾き |
| 6 | 価格と長期MA、長期MAフィルターのON/OFF |
| 7 | 防衛ライン。実注文ではない |
| 8 | 現在の足のグランビル判定。未確定なら「足の確定待ち」 |
| 9 | 選択時間足のATR、色区分、取得元バーの終了時刻 |
| 10 | ATR×倍率の丸め前の値 |
| 11 | 選択方式による採用幅候補と円の値幅 |
| 12 | 入力した通貨数での値幅換算額 |
| 13 | 手入力の参考スプレッドと金額 |
| 14 | 時間足の違い、ATR取得状況、手入力値に対する注意等 |

1時間足を開けば、ダウ・波動・グランビル・MA乖離④は1時間足の判定です。ATRだけを5分足にしても、売買サインが5分足へ切り替わるわけではありません。異なる時間足を組み合わせたときは注意を表示します。

パネルのグランビル行は、直前のサインを現在も有効な注文指示として持ち越しません。新しい足になれば「足の確定待ち」に戻ります。過去の確定サインは、その足のチャート上に残ります。

MAや現在値からの距離線は形成中の足でも動きます。「確定足のみ」は売買サイン、トレンド状態更新、波動候補更新などに適用するルールで、画面上のすべての描画を止めるという意味ではありません。表示パネルをOFFにしたときはセルを消去します。

### USDJPY・3,000通貨で20pipsと25pipsを比較する設定

まず「幅候補の計算方法」を `固定pips` にし、「固定幅」を20.0にします。25pipsを比較するときだけ固定幅を25.0へ変えます。「固定幅」の入力だけを変えても、方式が `ATR×倍率` のままなら固定幅は適用されません。

| 比較条件 | 設定 | 3,000通貨での値幅換算 |
|---|---|---:|
| 固定20pips | 固定pips / 20.0 | 600円 |
| 固定25pips | 固定pips / 25.0 | 750円 |
| ATR＋下限20pips | ATR×倍率＋下限 / 下限20.0 | ATR由来の幅が20pipsを超えると600円より大きくなる |

これは以前の検討を再現するための比較設定であり、最適値、損失上限、ノイズで決済されない幅を保証するものではありません。1時間足のシグナルへの適合性も未検証です。

本コードの数量3,000は `3,000 × 値幅（円）` を計算するだけです。FOREX.comの数量欄に何を入力するかは、その画面の通貨数・ロット単位に合わせて別途確認してください。証拠金、維持率、レバレッジ、手数料、スワップ、スリッページは計算していません。

参考スプレッド2.6pipsなら、USDJPY・3,000通貨の差額は78円相当です。これは現在のスプレッドを取得した値ではありません。参考値を8.2へ変えれば246円と注意表示になりますが、変動を自動検知した結果ではありません。

幅換算額とスプレッド額は別々の参考情報として示し、合算した「損失上限」は表示しません。実際の約定価格から損益を計算する場合、既に含まれたスプレッド相当額をさらに二重計上しないよう注意してください。

元資料にあった4〜6pips損切り・6〜10pips利確という短期例と、20〜25pipsを唯一の出口にするトレール運用は、別の決済ルールです。この修正版はどちらの戦略成績も検証していません。
